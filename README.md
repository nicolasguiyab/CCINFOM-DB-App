This is the repository for the Machine Project "DATABASE APPLICATION" For Information Management class of DLSU

The Base BD zip contains the tables in mySQL that will be used in the machine project

mysql connect is the connector for the java to sql

MainOutputs contains the files for the project, each categorized into packages:
 -App package - contains the main class
 -DAO package - contains the DAO (Data Accessing Object) and logic for the application
 -Database package - contains the connection code
 -Model package - contains the getters for each table in the sql
